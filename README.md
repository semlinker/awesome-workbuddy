# Awesome WorkBuddy

> 精选的 Tencent WorkBuddy 学习资料、实战案例、Skills 与扩展资源。欢迎提交经实际验证、对使用者有帮助的内容。

[WorkBuddy](https://www.codebuddy.cn/work/) 是腾讯推出的全场景 AI 办公工作台：用户可用自然语言发起任务，由它规划并执行文件处理、内容创作、数据分析、设计创意和代码等工作，并交付可验收的结果。它也提供 Skills、连接器和 MCP 等扩展能力，适合将重复工作沉淀为可复用的工作流。

> **说明：** 本清单是第三方资源索引，并非腾讯官方文档。工具功能、安装方式和可用性会随版本变化；执行涉及本地文件、账号授权、外部连接器或敏感数据的任务前，请先阅读官方说明并确认权限范围。
